# Frontier Bastion Client

Unity mobile client workspace for Frontier Bastion.

## Branch Strategy

- `main`: stable production-ready history.
- `develop`: integration branch for ongoing work.
- `feature/*`: feature branches from `develop`.
- `release/*`: release stabilization branches from `develop`.
- `hotfix/*`: urgent fixes from `main`.
- `support/*`: long-lived maintenance branches if needed.

The actual Unity project scaffold is intentionally deferred until the client implementation scope is selected.
